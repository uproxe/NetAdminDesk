# Перенос на другой компьютер и между ОС

Пароли в рабочей базе зашифрованы средствами конкретной системы (DPAPI на Windows, Keychain на macOS, libsecret на Linux) или мастер-паролем. Ключ системного хранилища нельзя перенести на другой компьютер, поэтому для переноса **с паролями** используется зашифрованный файл `.nadx`.

## Только устройства — быстрый перенос списка

Если нужно передать на другой компьютер только список устройств (свой второй компьютер, коллега):

1. «Устройства → **Экспорт**» → выберите устройства → «Файл переноса NetAdmin Desk» → по желанию ключи хостов и пароли (с паролями файл шифруется паролем файла) → «Сохранить файл…».
2. На другом компьютере: «Устройства → Импорт → **С другого компьютера**» → выберите файл `.nadevices` → посмотрите список → «Импортировать».

Устройства, которые там уже есть (тот же адрес, порт и логин), не задвоятся: их можно оставить как есть или обновить. Группы и папки создаются по имени, узлы-посредники сохраняют связь. Подробно — [USER_GUIDE.md, раздел 2](USER_GUIDE.md#перенос-устройств-на-другой-компьютер).

## Все данные: Windows ↔ macOS ↔ Linux (рекомендуемый способ)

На старом компьютере:

1. «Настройки → Импорт и экспорт → Зашифрованный экспорт всех данных…».
2. Задайте пароль файла (не короче 8 символов). При необходимости включите историю команд.
3. Перенесите файл `netadmin-ГГГГ-ММ-ДД.nadx` на новый компьютер.

На новом компьютере:

1. Установите NetAdmin Desk и запустите. Встроенный справочник и TXT-заметки загрузятся автоматически.
2. Настройте хранение паролей («Настройки → Безопасность»): системное хранилище или мастер-пароль. **Если хранение паролей не настроено, пароли из файла не сохранятся** — программа сообщит, сколько паролей пропущено.
3. «Импорт зашифрованной копии…» → выберите файл → введите пароль → «Проверить файл». Будет показано, что содержит копия (дата, версия, количество устройств, паролей, команд…).
4. Выберите, заменять ли совпадающие записи и импортировать ли настройки → «Импортировать».

Что переносится: устройства и группы (Jump Host сохраняет связь), пароли, парольные фразы ключей и enable-пароли, ваши и изменённые записи справочника, отметки «Проверено», избранное, сценарии, заметки, профили диагностики, параметры шаблонов, известные ключи хостов, настройки (по выбору), история (по выбору).

Что не переносится автоматически:

- **файлы приватных ключей SSH** — в карточке устройства хранится только путь к ключу. Скопируйте ключи отдельно и при необходимости поправьте путь (пути Windows и macOS/Linux различаются);
- каталог `backups/` с конфигурациями — скопируйте его вручную в каталог данных на новом компьютере (записи о копиях в базе ссылаются на старые пути; список копий будет перенесён, если перенести и базу целиком, см. ниже).

Известные ключи хостов: если на новом компьютере для того же адреса уже сохранён **другой** ключ, он не заменяется — такое расхождение нужно проверить вручную.

## Тот же компьютер или та же ОС, режим мастер-пароля

Можно просто скопировать каталог данных целиком (при закрытой программе) — пароли откроются тем же мастер-паролем.

## Переносимый режим (флешка)

Создайте папку `netadmin-data` рядом с исполняемым файлом программы — данные будут храниться в ней. Используйте режим мастер-пароля: системное хранилище привязано к компьютеру.

## Перенос справочника без паролей

- JSON-экспорт — команды, сценарии, заметки, группы, устройства (без паролей).
- TXT-экспорт — свои и импортированные записи в исходном виде.

## Обновление программы

Новая версия использует ту же базу. При обновлении встроенного справочника:

- ваши правки встроенных записей и скрытые записи сохраняются;
- избранное, отметки «Проверено» и вручную заданный уровень риска сохраняются;
- записи встроенных TXT-заметок обновляются вместе со справочником; изменённые вами записи не перезаписываются.

### Обновление до 1.0.0

- Встроенные TXT-заметки в 1.0.0 обезличены. При первом запуске записи из старых заметок в базе заменяются новыми (с нейтральными адресами и именами); записи, которые вы изменяли сами, остаются как есть. Если вам нужны свои исходные заметки — импортируйте свой файл: «Настройки → Импорт и экспорт → Импорт TXT» (на вашем компьютере они останутся только у вас).
- 12 команд баз данных переехали из раздела «Linux» в новый раздел «Базы данных»; избранное и отметки сохраняются.
- Схема базы не менялась, но откат на 0.11 с той же базой не рекомендуется: записи раздела «Базы данных» старая версия не знает. Перед обновлением сделайте копию базы (BACKUP.md) — к ней можно вернуться.

Перед обновлением рекомендуется сделать копию базы или `.nadx` ([BACKUP.md](BACKUP.md)).
